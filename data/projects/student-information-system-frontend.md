**Student Information System (SIS)** — A secure, role-based platform built with React 19, Vite, and Tailwind CSS, integrated with a decoupled CodeIgniter 4 REST API. Features dedicated Admin and Faculty workflows, real-time dashboards, GPA analytics, and third-party service integrations.

### Key Features

**Architecture & Security**

* Role-Based Access Control (RBAC) with protected routes and permission-based Admin/Faculty access.
* Modular, decoupled architecture using Axios service layers to separate API logic from the UI.

**Administrative Tools**

* Full CRUD management for students, courses, and grading systems.
* Real-time billing and balance tracking with QR-code receipt generation.
* GPA calculation and analytics dashboards powered by dynamic data visualization.

**Integrations**

* Live weather data integration for dashboard telemetry.
* On-demand QR code generation via external microservices.
* Context-aware motivational content fetched from a remote API to enhance user experience.
